# 💳 Credit Class Prediction

A machine learning project developed to predict customer credit class using various classification algorithms. The project follows a complete end-to-end machine learning pipeline, including data cleaning, feature engineering, variable transformation, model building, evaluation, and performance comparison to identify the best-performing model.

---

## 🚀 Features

### 📊 Data Preprocessing
- Data Cleaning
- Missing Value Handling
- Outlier Detection and Treatment
- Duplicate Removal
- Feature Scaling
- Encoding Categorical Variables

### ⚙️ Feature Engineering
- Variable Transformation
- Feature Selection
- Data Standardization
- Feature Extraction

### 🤖 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

### 📈 Model Evaluation
- Accuracy Score
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC-AUC Score
- Cross Validation

### 📉 Data Visualization
- Correlation Heatmap
- Distribution Plots
- Feature Importance
- Performance Comparison Charts
